# Credit Scoring Model

## Objective
Predict whether a loan applicant is a good or bad credit risk.

## Machine Learning Type
Supervised Learning

## Problem Type
Binary Classification

## Features
Financial and personal information of loan applicants.

## Target
Credit Risk (Good / Bad)

## Algorithms
1. Logistic Regression
2. Decision Tree
3. Random Forest

## Evaluation Metrics
1. Precision
2. Recall
3. F1-Score
4. ROC-AUC
